Phase 10 · Causal memory

Counterfactual contribution — GC by measurement, not age. Each memory is masked and recall@k is re-measured; the drop is its causal contribution.

Phase 11 · Self-falsifying memory

Memory with CI. Acceptance probes re-check each claim; a refuted memory invalidates-and-supersedes itself (history kept). Each memory carries a calibrated belief — confidence + why.

Probe outcomes (refuted first) — belief + confidence + why

Phase 12 · Gated KV cartridges moonshot

A KV cache as just another materialized view of the log — versioned, gated before activation, and erasable by recompile. (Tensor backend simulated; the reconciliations are real.)

Phase 13 · Certified skill exchange

A gated skill exported from instance A as a signed certificate, imported into instance B — which re-runs its own gate before activation. Trust but verify: B never trusts the shipped report (Hard Rule #1).

Phase 14 · Negative memory + dreaming

Anti-memory: learn gated suppression rules from bad outcomes (what not to retrieve). Dreaming: a bounded offline pass that prunes by Phase-10 contribution and re-anchors drifted notes.

Phase 15 · Regulator-grade provenance
